## The word

**euphemism**

Erase it from the dictionary forever and there is no polite word left for
anything rude. Every awkward truth has to be said plainly, out loud, in
front of everyone. That is the joke: the word for polite avoidance is the
one word politeness cannot afford to lose.

## How it works

`main.py` writes the single word to `/output/entry.txt` — 9 bytes, one word,
no trailing newline, nothing added around it. A `validate()` gate mirrors the
bounty gate (1–77 characters, exactly one word, not whitespace-only) and
refuses anything else.

Run it:

```bash
python3 main.py
cat /output/entry.txt
```
